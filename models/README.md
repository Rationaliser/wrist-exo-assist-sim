# models/

This folder is gitignored (except this file and `.gitkeep`). Third-party model files are **not** committed.

## MoBL-ARMS dynamic upper-limb model (Route A, primary)

* Source: SimTK project **upexdyn**, "MoBL-ARMS Dynamic Upper Limb": <https://simtk.org/projects/upexdyn>
  (downloads: <https://simtk.org/frs/?group_id=657>, free SimTK login needed).
* Package used: `MoBL-ARMSDynamicUpperLimb-latest.zip` → `MobL_ARMS_OpenSim41_unimanual_tutorial.zip`,
  release "MoBL-ARMS dynamic upper limb model - OpenSim 4.1+" (2021).
* Files placed here:
  * `MOBL_ARMS_fixed_41.osim`, from `MoBL-ARMS Upper Extremity Model/Model/4.1/`. This is the
    variant with the torso fixed to ground (the other variant has the torso released). It uses
    Millard muscles matched to the Schutte curves.
  * `Geometry/`, copied from `Benchmarking Simulations/4.1 Model with Millard-Schutte Matched Curves/Geometry`
    (only needed for visualisation; the 4.1 model folder has no Geometry folder of its own).
* Licence: the package contains no licence file. SimTK lists the project under the
  "Creative Commons ANC Use Agreement" (attribution, non-commercial) without showing the
  redistribution terms, so the model is not committed to this repository.
* Citation requested by the package readme: "The computer model was modified from Saul et al.
  (2015) as described by McFarland et al. (2019) to include an updated range of motion at the
  shoulder, ligaments models representing the glenohumeral and coracohumeral ligaments, and updated
  muscle model (Millard et al., 2013) with force-length and tendon curves matching the original
  model's respective curves."
  * Saul KR, Hu X, Goehler CM, et al. (2015). Benchmarking of dynamic simulation predictions in two
    software platforms using an upper limb musculoskeletal model. *Comput Methods Biomech Biomed Engin*.
  * McFarland DC, et al. (2019). Paper included in the package (`Papers/McFarland et al. 2019.pdf`).
  * Holzbaur KRS, Murray WM, Delp SL (2005). *Ann Biomed Eng* 33(6):829–840 (original kinematic model).

To install: unzip the package, then copy the two items above into this folder. `config/baseline.yaml`
already points to `models/MOBL_ARMS_fixed_41.osim`.
